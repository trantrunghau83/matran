# Phần mềm Xây dựng Ma Trận & Bản Đặc Tả Tin Học THCS (GDPT 2018)

Dự án này là một ứng dụng Web được xây dựng bằng Python (Streamlit), giúp giáo viên Tin học dễ dàng thiết lập ma trận đề thi từ lớp 6 đến lớp 9 theo chuẩn Chương trình GDPT 2018.

## Tính năng chính:
- 📖 Chứa sẵn kho dữ liệu các Chủ đề (A, B, C, D, E, F) của môn Tin học.
- 🧮 Tự động thiết lập bảng ma trận theo chuẩn: TNKQ, Đúng/Sai, Tự luận dựa trên các mức độ nhận thức (Nhận biết, Thông hiểu, Vận dụng).
- 📥 **Xuất trực tiếp ra file Microsoft Word (.docx)** để tiện in ấn và nộp cho Tổ chuyên môn.

## Cài đặt và Chạy cục bộ
1. Clone repository này về máy tính.
2. Cài đặt các thư viện: `pip install -r requirements.txt`
3. Khởi chạy ứng dụng: `streamlit run app.py`
